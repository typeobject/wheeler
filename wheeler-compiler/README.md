# Wheeler compiler

This directory is the canonical Wheeler-written compiler package. Its sources under `src/main/wheeler` define the compiler, scanner, verifier, codecs, and driver slices promoted out of examples. `compiler/Driver.w` is the stateless importable compiler API. `compiler/frontend/Tokens.w` owns token identities and scalar decoding. `compiler/syntax/StatementForms.w` owns bounded statement classification, so the token file does not moonlight as a parser. `compiler/backend/LocalTypes.w` owns statement-local type-table emission rather than letting the instruction encoder grow moss. `compiler/frontend/helpers/Programs.w` owns typed helper and entry sequence construction. `MinimalCompiler.w` is the small executable wrapper that publishes the returned verified range. Identity tools therefore reuse the compiler instead of maintaining a shadow copy with a fake moustache. `wheeler.package.yaml`, the exact lock, and canonical workspace sources are the package boundary. Workspace builds reconstruct dependency archives in memory. Generated `vendor/` closures are for exported offline bundles, not source control.

Java stage-0 code does not live here. The temporary seed is isolated in [`../bootstrap/stage0`](../bootstrap/stage0), which compiles this package into a stage-1 `.wbc` compiler. Stage 1 must compile these same sources into a byte-identical stage 2, and the resulting seed update must also satisfy the diverse-bootstrap and provenance rules in WIP-0007. Fixed points catch drift. They do not exorcise a malicious ancestor by repetition.

Examples consume this package through exact locks. They do not carry compiler implementation copies. The bounded source profile compiles typed zero-argument result helpers, one- and two-argument signed and Boolean helpers. Literal and prior-local arguments cross the same verified `CALL_VALUE` path. New compiler features land here in Wheeler after the bootstrap profile can express and test them. Java additions require a concrete stage-crossing reason and an accompanying deletion condition.
