# Instructions for Returning

```text
FIELD MANUAL 7C
Vessel class: long-range courier
Provenance: disputed
Revision authority: none
```

No manufacturer admitted to printing the volume. Its oldest paper came from a mill that had closed before the *Vela* was laid
down, while its newest annotations referred to a compiler profile released six months earlier. The binding had been repaired in
three ports with three incompatible ideas about permanence.

On the flyleaf, beneath a list of former owners, someone had written the manual's only governing rule.

```text
Name no distinction before an experiment requires it.
Retain every name that survives the experiment.
```

Four chapters had passed source, artifact, and execution review.

1. [Home](00-return-to-which-state.md)
2. [Departure](01-write-the-first-instruction.md)
3. [Two Signals](02-ask-the-machine-to-act.md)
4. [The Archive](03-one-thing-to-remember.md)

The remaining signatures stayed sealed. Their edges carried five titles and no claims of completion.

```text
CONTRIBUTIONS THAT CANCEL
TWO SYSTEMS WITH ONE DESCRIPTION
THE CONTRACT MACHINE
THE FAR INSTRUMENT
WEATHER
```

A final note occupied the inside cover. Different ink had amended it twice, but nobody had crossed it out.

```text
A successful return does not erase the journey.
It restores what was promised, preserves what matters,
and accounts for what remains.
```
