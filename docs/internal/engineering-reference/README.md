# Public reference migration archive

These snapshots preserve the ten public reference pages as they stood before the
instrument-appendix migration. The unusual `.md.snapshot` suffix keeps the old
links, prose, and front-matter-free source outside the maintained manual graph.
The files remain engineering history rather than a second public authority.

The public routes under `docs/public/reference/` now carry the concise accepted
contracts. `docs/internal/world/public-reference-migration.md` maps every former
section to its public appendix or to this implementation ledger.
